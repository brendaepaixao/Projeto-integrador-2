O presente foi desenvolvido durante o 3º semestre dos cursos de TADS e TSI — Segunda Etapa, com foco na criação de interfaces web e na modelagem de banco de dados para um sistema de gestão universitária.

A proposta do trabalho teve como base os cenários de casos de uso desenvolvidos na primeira etapa do Projeto Integrador, permitindo a continuidade do desenvolvimento do sistema por meio da prototipação das telas e da estruturação das informações.

O projeto foi voltado principalmente para a construção das interfaces utilizando HTML5 e CSS3, buscando organização visual, padronização e representação funcional do sistema. Além disso, foram desenvolvidos scripts SQL utilizando comandos DDL (Data Definition Language) e DML (Data Manipulation Language), responsáveis pela criação, estruturação e manipulação do banco de dados.

Durante o desenvolvimento, foram criadas páginas relacionadas ao gerenciamento acadêmico e administrativo, incluindo lista de alunos, docentes, fornecedores, pessoas, cadastro de pessoa física, cadastro de pessoa jurídica e página inicial do sistema.

O trabalho teve como objetivo aplicar conceitos de desenvolvimento front-end, modelagem de dados, organização estrutural de sistemas e integração entre interfaces e banco de dados, proporcionando experiência prática no desenvolvimento colaborativo e na construção de soluções voltadas para ambientes acadêmicos.
